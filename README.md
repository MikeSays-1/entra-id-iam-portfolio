# Microsoft Entra ID IAM Portfolio

This portfolio documents my Microsoft Entra ID identity and access management work within **Northwind Medical Systems**, a simulated enterprise environment created to model real-world IAM operations.

The projects focus on workforce identity administration, identity lifecycle management, access governance, role-based access control, automation, and privileged access concepts using Microsoft Entra ID, Active Directory, PowerShell, and Microsoft Graph.

## Portfolio Projects

### Part 1 — Identity Lifecycle Management (JML) & User Provisioning
Covers Joiner-Mover-Leaver processes, user provisioning, group membership, access assignment, and account lifecycle administration.

**Project:** [Part 1. Identity Lifecycle Management (JML) & User Provisioning](https://github.com/MikeSays-1/Entra-ID-JML-Lab)

### Part 2 — Access Reviews, Certification & Identity Governance
Covers access reviews, access certification, entitlement validation, remediation, and identity governance concepts.

**Project:** [Part 2. Access Review, Certification & Identity Governance](https://github.com/MikeSays-1/Entra-ID-Access-Review-Lab)

### Part 3 — Role Mining, RBAC & Least Privilege
Covers role analysis, role-based access control, permission alignment, and least-privilege access.

**Project:** [Part 3. Role Mining, RBAC Implementation & Least Privilege](https://github.com/MikeSays-1/Entra-ID-Role-Mining-RBAC-Lab)

### Part 4 — Microsoft Graph & PowerShell Automation
Covers identity administration and access-management automation using PowerShell and Microsoft Graph.

**Project:** [Part 4. Micosoft Graph & Powershell: Automated Access Provisioning & Remediation](https://github.com/MikeSays-1/Entra-ID-Access-Automation)

### Part 5 — Privileged Access, JIT, PIM & Break Glass
Explores privileged identity concepts including just-in-time access, Privileged Identity Management, emergency access, and standing privilege reduction.

**Project:** [Part 5. Privileged Access Management - JIT & PIM & Break Glass](https://github.com/MikeSays-1/Entra-ID-JIT-PIM)
